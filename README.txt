2. HOW TO HOST ONLINE (100% FREE & INSTANT IN 2 MINUTES)
--------------------------------------------------------------------------------
This website is 100% static (HTML5, Vanilla CSS3, Vanilla JS). It requires NO
backend, NO database, and NO build steps. You can host it on any free static
web host:

OPTION 1: Netlify Drop (EASIEST & FASTEST - No Coding / No Git Required!)
1. Open your browser and go to: https://app.netlify.com/drop
2. Sign in with Google, GitHub, or create a free Netlify account.
3. Drag and drop this ENTIRE "Kajal Didi Final Birthday" folder directly into
   the upload circle on the Netlify webpage.
4. Within 10 seconds, Netlify will deploy your website and provide a free
   live HTTPS link (e.g., https://kajal-didi-birthday.netlify.app).
5. Share the link with Kajal Didi on WhatsApp!

OPTION 2: GitHub Pages (Permanent & Free)
1. Create a free account on https://github.com if you haven't already.
2. Create a new repository named "kajal-didi-birthday".
3. Upload all files from this "Kajal Didi Final Birthday" folder into the
   repository root (ensure index.html is in the root directory).
4. Go to Repository Settings -> "Pages" (in the left sidebar).
5. Under "Branch", select "main" (or "master") and folder "/ (root)", then
   click "Save".
6. In 1 minute, your website will be live at:
   https://<your-username>.github.io/kajal-didi-birthday/

OPTION 3: Cloudflare Pages / Vercel
1. Log in to Cloudflare Dashboard (Pages) or Vercel.com.
2. Select "Upload Assets" or connect your GitHub repository.
3. Keep the Build Command EMPTY (static site - no build needed).
4. Output directory: "." (root).
5. Click Deploy!
